# Role: first-time user on a fresh machine

Pretend you have never seen this project. Using ONLY the README, docs and the tool's own help/UI, install it
in a clean directory and reach first value. Count every step and note the time, every doubt, every error, every
place the docs and the behaviour disagree. Run real commands where you can. Evidence for doc problems is the doc
line; for behaviour problems, the code line responsible. Category is usually user_value.
